Respaldo

Descarga una copia de todos los datos (proyectos, seguimiento, bitácora, ambientes y configuración). Hazlo al menos una vez al mes y guarda el archivo en una carpeta corporativa. El JSON sirve para restaurar; el Excel es para consultar.

Restaurar desde un archivo

Sirve para recuperar datos o migrar un respaldo JSON. «Combinar» agrega y actualiza sin borrar lo que ya existe; «Reemplazar» deja cada colección exactamente como el archivo (borra lo que no esté en él).
